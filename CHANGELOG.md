# Changelog

## Theme Composer

- Added Easy Mode above the existing Enterprise Theme Engine.
- Added visual presets, custom 3-color mixes, mood selection, intensity and deterministic variations.
- Added Auto WOW generation using the existing Material 3 and WCAG token generator.
- Added generated mesh, ambient glow, surface tint, header, CTA, noise and vignette metadata with safe defaults.
- Persisted the simple customer configuration in `app_settings.theme_composer` while preserving old themes.
